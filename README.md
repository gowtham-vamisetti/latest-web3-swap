## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/gowtham-vamisetti/latest-web3-swap.git
   ```
2. Navigate to the project directory:
   ```bash
   cd latest-web3-swap
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Run the application:
   ```bash
   npm start
   ```
